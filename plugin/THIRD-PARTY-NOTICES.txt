===============================================================================
Bundled skill reference content
===============================================================================

  papyrus-reference
      The Papyrus / SKSE function reference bundled with this skill is generated
      from BellCube's papyrus-index (github.com/BellCubeDev/papyrus-index). It
      includes function signatures and doc-comment text drawn from vanilla
      Skyrim, SKSE, and a set of popular SKSE-plugin sources. That
      API-declaration content (doc-comments included) is redistributed on the
      same API-declaration / fair-use basis under which BellCube's index
      assembles it; copyright in the underlying script comments remains with
      their original authors (Bethesda; the SKSE team; the individual plugin
      authors). Credit and thanks to BellCube for the papyrus-index.

  mutagen-reference
      The record-schema reference is generated by reflection over the
      Mutagen.Bethesda.Skyrim library and is a derivative of Mutagen; it carries
      the same GPL-3.0-only terms as the rest of the Mutagen surface above. (The
      server's corpus.json rulebook is the same generated derivative.)

  skypatcher-authoring / spid-authoring / kid-authoring
      Original grammar-reference prose describing the (uncopyrightable)
      SkyPatcher, SPID, and KID configuration grammars; no upstream source is
      vendored. With thanks to Zzyxzz (SkyPatcher) and to powerofthree (SPID and
      KID, MIT), whose public documentation the grammar facts were drawn from.

  papyrus-optimization
      A Papyrus performance-review skill (original reference prose plus the
      review workflow, describing Papyrus cost patterns and their fixes),
      contributed to houseCARL by DrHeisen. It is an original community
      contribution, conveyed as part of this GPL-3.0-only combined work under
      the same terms. With thanks to DrHeisen - houseCARL's first
      community-contributed skill.
