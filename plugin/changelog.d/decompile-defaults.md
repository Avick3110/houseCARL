- **`decompile_script` now marks any call, native, vanilla or mod, whose trailing `None` arguments it leaves out of the text: `;/ +N omitted: None, … /;` before the close paren, one `None` per argument, so the shown arguments plus N are what the call passes.** Decompile a script that calls `RemoveItem(akItem, 1, true)`: it reads `RemoveItem(akItem, 1, true ;/ +1 omitted: None /;)`.
