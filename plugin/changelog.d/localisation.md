- **Non-English installs now read and write names in the game's language.** houseCARL reads `sLanguage` from your profile's Skyrim.ini and opens every plugin in that language and its code page (Windows-1251 for Russian, 1250 for Polish, and so on). Before, a German, Russian or other non-English install read blank names, and a patch that overrode a vanilla, DLC or Creation Club record could carry a blank or English name. If you play in another language, re-check the patches you made with an earlier release. A language your game has no string tables for is refused in one sentence naming it.
- **Creation Club names resolve when the plugin and its strings archive sit in different mod folders**, as with cleaned Creation Club masters. Check: `housecarl_records formids=["04D049:ccBGSSSE001-Fish.esm"]` shows a name, not "(unresolved localized string)".
