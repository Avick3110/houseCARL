## What these references are

corpus (2026-07-03). They are NOT generated by construction — 99.7% of CommonLibSSE headers carry zero doc
comments, so there are no semantics to generate (the evaluation that chartered this project settled this).
The references are the *author-facing* transform of the dev-side research docs; the research docs remain the
full-detail source of record.

## The [BUILD-TEST] debt — what an empirical pass (V0–V3) still owes

The mines marked every runtime-unprovable claim `[BUILD-TEST]`; the references reframed those as "Not yet
verified in-game" sections (all nine carry one). The debt is **read-from-source, not yet run**. The
load-bearing gates, by reference:

- **toolchain-setup** — the current-lineage *minimal CMake* scaffold is an unbuilt assembly (the xmake /
  submodule route is the proven one); ClibDT current state; libxse runtime coverage.
- **plugin-skeleton** — trampoline allocation is capacity-bounded, not time-gated (needs an AllocTrampoline-
  at-`kDataLoaded` observation); GOG/Epic store-variant version reconciliation; preload-phase interface legality.
- **load-failures** — the exact VR (`sksevr.log`) emitted-line shapes and the pre-AE SE loader gate;
  GOG/Epic address-library filename reconciliation.
- **event-sinks** — the raw-input-sink traversal (production-unattested; no exemplar sinks `InputEvent`);
  all runtime firing/threading/delivery claims; 16 opaque forward-declared event payloads.
- **native-papyrus-functions** — thread the VM invokes natives on; latent-function stack mechanics at runtime.
- **hooking** — SPID's `stl::install_hook` dispatch body (external submodule, unfetched); versionlib `.bin`
  unpack semantics; whether a swapped `RelocateVirtual` index reliably CTDs vs silently no-ops.
- **multi-runtime** — the CTD-vs-silent-misread distinction for several footguns.
- **threading-and-persistence** — off-thread-mutation corruption is doc-asserted, not observed; the exemplar
  CommonLib submodule SHAs (shallow clone can't verify objects).
- **plugin-dissection** — mostly method (low runtime-risk); the SPID mechanism map is read-confirmed.

Full residuals live in each research doc's "Residuals / open gaps" section. The V0–V3 validation ladder in
`../research/_research-roadmap.md` §3 is the plan to burn them; it is **owed to Aaron** and runs on his
machine/runtime (SE 1.6.1170). AE-other/VR claims stay doc-level until then.

## Lineage watch (flag to Aaron)

The charter locks **alandtse `ng`** as current and nothing here challenges that. But the M1 mine surfaced,
with evidence, that **`libxse/commonlibsse` is an emerging fourth lineage** — libxse's flagship template
moved off NG onto it 2026-07-01 (the `REX::INFO` tell). Not a switch signal; a drift worth watching on the
next corpus refresh. The references teach recognizing it (so borrowed libxse code is read correctly), not
adopting it.

## Staleness duty

These references are hand-curated from a point-in-time snapshot of a **living** upstream (`ng` was pushed
the day before the pins). On any refresh: re-pin the corpus (record new commits here), re-run the affected
mine(s), and re-check the lineage watch above. The generated-by-construction guarantee that protects
`mutagen-reference` / `papyrus-reference` does **not** apply here — this corpus can silently drift, so the
re-check is a real duty, not a formality.
