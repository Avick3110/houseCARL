# `VisualEffect`

**Source:** `vanilla` • **Extends:** `Form` • **Flags:** Hidden

## Functions

### `Play(akObject, afTime, akFacingObject)`

**Flags:** Native

Plays this visual effect on the specified object, for a certain length of time (negative for infinite) and possibly facing another object

**Parameters**

| Name | Type | Required | Default |
|---|---|---|---|
| `akObject` | `ObjectReference` | ✓ |  |
| `afTime` | `Float` |  | `-1` |
| `akFacingObject` | `ObjectReference` |  |  |

### `Stop(akObject)`

**Flags:** Native

Stops this visual effect from playing in the specified object

**Parameters**

| Name | Type | Required | Default |
|---|---|---|---|
| `akObject` | `ObjectReference` | ✓ |  |
